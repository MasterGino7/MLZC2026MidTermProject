# MLZC2026MidTermProject
MidTermProject for MLZoomCamp 2026. Credit Card Fraud Detection.
The DataSet is about fraud detection on credit card transactions, the dateset is imbalanced as only 1.70% of the transactions are fraud. This project will try to get "precision" and "accuracy" on "good" levels while considering "business costs".
4 Different ML models were tested on the dataset (Logistic Regression, Decision Tree, Random Forest and XGBoost). After reviewing all results, a Logistic Regression model is the winner.
